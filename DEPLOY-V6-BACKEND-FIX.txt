ISHT DEVTA ₹51 FUNNEL — V6 BACKEND FIX
======================================

WHAT WAS FIXED
- Main booking payment is hard-locked to ₹51 (5100 paise).
- Dakshina Razorpay order creation fixed for ₹121 / ₹201 / custom ₹121+.
- Navagrah Remedies Razorpay order creation fixed at ₹99 (9900 paise).
- New unique Netlify function endpoints added so old/stale functions cannot silently control the new funnel.
- Legacy function filenames were ALSO replaced with the V6-safe code, so cached older frontend calls cannot charge ₹201.
- Payment amount safety checks added in the browser BEFORE Razorpay can open.
- A backend health endpoint was added.
- If a URL was opened from ChatGPT and contains utm_source=chatgpt.com, the page removes that parameter from the visible address bar. Normal Meta/Google UTMs are not removed.

- /api/create-isht51-order
- /api/create-dakshina-v2-order
- /api/create-navagrah99-order
- /api/verify-isht-payment
